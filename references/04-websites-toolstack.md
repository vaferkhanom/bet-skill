## 5. 1xBet match page — how to read

Base `https://1xbet.com/en/live` (Live) + `https://1xbet.com/en/line` (pre). Open match → tabs:

- **Probability of Winning widget:** margin-included implied % from 1xBet odds (1.80 ≈55.5% pre-margin). Convert to fair (`1/%`), compare to Pinnacle no-vig / your xG model. If 1xBet 45% but model + OddsPortal avg 52% → value. If heavily public + dropping elsewhere → trap. Never bet on widget alone.
- **Statistics tab:** W-L, form, H2H, goal avgs, possession, SoT, xG, clean sheets. Combine attack (goals/SoT/xG) vs defence. Check H/A split + H2H. High xG + low goals = positive regression (back Over next). No methodology disclosed — verify xG on Understat/FBref.
- **Live Tracker + Stats:** animated pitch (ball/attacks/shots/poss/fouls), timeline, momentum after subs. Stream if funded/active bet else tracker. If possession + shots surge post-sub but score same → back before compression. Cash-out full/partial on slip — use when momentum flips. Odds update seconds (fast EPL/UCL, slower low liquidity). Markets suspend post-goal/red/pen then reopen — 60' same bet ≠ 30' value.
- Mistakes: single-stat reliance, ignoring XI/weather/motivation, no live re-check, no price vs OddsPortal best. Guides: https://stator.com/1xbets-analytics-tools-how-to-gain-betting-insight/ , https://webinar.samueljohnson.in/how-to-use-1xbet-statistics-and-analytics-for-informed-betting/

## 7. Recommended stacks

- Pre-match: OddsPortal/BetExplorer (price+drop) + FBref + Understat (xG/xPts) + FootyStats (BTTS/O-U/corners/cards%) + Transfermarkt/MissesNextMatch/RotoWire (XI) + Statz/FootyMetrics if cards + Windy if totals.
- Live: SofaScore/FotMob momentum + xG + Flashscore speed + 1xBet tracker + cash-out discipline.
- Modelling: Football-Data.co.uk CSV + ClubElo + StatsBomb Open Data via `soccerdata` Python lib.
- Track 1xBet ROI by market (e.g. https://www.mybets.gg/sportsbook/1xbet).
